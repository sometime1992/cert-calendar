# 자격캘린더 (Cert Calendar) — v1.0

국가기술자격 준비자를 위한 **개인 자격증·학습 계획 관리 PWA**입니다. 지도는 사용하지 않습니다.

## 현재 구현된 기능
- 관심 자격증 추가/수정/삭제, 등급별 검색 예시 및 사용자 정의 이름 등록
- 필기 접수·시험, 실기 접수·시험, 합격 발표일 **직접 등록**, 정확한 로컬 D-day 계산
- 월간 달력에 시험일·접수일·공부 할 일 표시
- 날짜별 공부 체크리스트 추가/완료/삭제
- 공부 타이머 (시작·일시정지·완료 기록), 이번 주 목표 대비 학습량
- 브라우저 localStorage 자동 저장, JSON 백업/복원, 전체 초기화
- 모바일 반응형 UI, PWA 설치 지원, 키보드 접근성
- Cloudflare Pages Functions(`/api/status`, `/api/schedules`) 기반 향후 API 연동 준비

## 한계 / 데이터 신뢰성
**v1.1에서는 종목코드를 지정해 공식 시험 일정을 조회하고 선택한 회차를 내 일정에 등록할 수 있습니다.** 자격증 검색에 표시되는 이름들은 빠른 등록용 예시일 뿐, 공공데이터 API에서 읽어 온 최신 전체 종목이 아닙니다. 입력한 시험일과 접수일은 개인 메모로 처리하며 공식 일정으로 표시하지 않습니다. 공식 일정은 공공데이터 API 원본을 서버측에서 조회하며, 실제 접수 전 Q-Net 공고를 다시 확인해야 합니다. 공식 시험 정보는 https://www.q-net.or.kr 에서 확인하세요.

공공데이터 출처(연동 계획):
- 국가자격 시험일정 조회 API https://www.data.go.kr/data/15074408/openapi.do
- 국가자격 종목 목록 정보 https://www.data.go.kr/data/15003024/openapi.do
- 국가기술자격 종목별 시험정보 https://www.data.go.kr/data/15003029/openapi.do

## 실행
`index.html`을 브라우저로 열면 주요 기능을 시험할 수 있습니다. PWA/Functions 검증은 HTTPS Cloudflare Pages 또는 로컬 HTTP 서버에서 진행하세요.

```bash
python -m http.server 8000
```

브라우저에서 http://localhost:8000 접속.

## GitHub 및 Cloudflare Pages
1. `cert-calendar` 리포지토리 생성 후 이 폴더의 **내용**을 최상위에 커밋 (`index.html`이 루트여야 함).
2. Cloudflare > Workers & Pages > Create > Pages > Connect to Git.
3. 저장소 선택, `main` 브랜치, Framework `None`, Build command **빈 칸**, Output directory `.`.
4. 첫 버전은 API 키 없이 개인 기록·일정 관리가 가능합니다.
5. 국가자격 시험일정 조회 API(15074408) 활용신청 승인 후 Cloudflare Pages 설정의 Secret `DATA_GO_KR_API_KEY`에 디코딩 인증키를 등록하고 새 배포를 적용합니다.
6. `/api/status`로 등록 여부를 확인하고 `/api/schedules?year=2026&jmCd=1320`으로 조회 테스트합니다. 키를 JS/HTML/GitHub에 올리지 마세요. 공식 API 승인과 실제 성공 응답은 배포 환경에서 확인해야 합니다.

## 개인 데이터
모든 학습 기록은 사용하는 브라우저의 localStorage에 저장됩니다. 브라우저 데이터 삭제, 기기 변경, 앱 삭제 시 기록이 사라질 수 있어 '내 데이터 관리 → 데이터 백업'을 활용하세요. 서버 계정, 여러 기기 동기화, 알림/푸시, 종목별 일정의 주기적인 자동 동기화는 미구현입니다.

## v1.1 — 공식 일정 조회
- 자격증 찾기 화면에서 시행연도와 종목코드를 선택해 **공식 시험 일정 조회**를 실행합니다.
- 종목코드 예시: 정보처리기사 `1320`, 전기기사 `1150`, 전기기능사 `7780`, 한식조리기능사 `7910`.
- 조회 결과에는 회차별 접수·시험·발표일이 표시됩니다. 필요한 회차만 **내 일정에 등록**하면 D-day와 달력에 반영됩니다.
- 서버는 Cloudflare Secret을 이용하며 인증키는 GitHub/브라우저에 전달하지 않습니다. 시험일 변경 가능성에 유의하고 Q-Net 공고를 최종 확인하세요.
- 공식 API에서 내려오는 응답이 없거나 에러가 발생하면 실패 사유를 표시하며 날짜를 생성하지 않습니다.

## v1.2 — 시험 일정 자동 입력
- 자격증을 검색해 등록하면 등록 화면 상단에서 공식 일정이 자동 조회됩니다.
- 시험 회차를 선택하면 접수일·필기일·실기일·발표일이 양식에 입력됩니다. 화면 아래 저장하기를 눌러 D-day 및 달력에 저장합니다.
- 종목 코드가 확인된 일부 자격증부터 지원합니다. 다른 자격증은 공식 종목 목록 API 검증 이후 연결합니다.
- Q-Net 공고의 실제 접수·시험 일정은 변동될 수 있으므로 반드시 공식 사이트에서 최종 확인하세요.


## v1.6 — Gemini API 기반 AI 문제 생성
- Cloudflare Workers AI 호출을 제거하고 Google Gemini REST generateContent API로 변경했습니다.
- Cloudflare Pages > Settings > Variables and Secrets에서 Secret 이름 `GEMINI_API_KEY`를 추가하세요. Google AI Studio에서 Gemini API용 키를 발급받습니다.
- 기본 모델: `gemini-3.5-flash-lite` (무료 이용 가능 여부와 할당량은 Google AI Studio의 프로젝트별 상태에 따름).
- 필요하면 일반 텍스트 변수 `GEMINI_MODEL`을 지원되는 모델명으로 지정할 수 있습니다.
- 기존 KV 바인딩 `QUIZ_RATE`는 유지합니다. 더 이상 Workers AI 바인딩 `AI`는 필수가 아닙니다.
- 학습자료 파일은 브라우저에서 텍스트를 추출합니다. 요청 시 추출 텍스트의 일부가 Cloudflare 서버를 거쳐 Gemini에 전달되며 원본 파일 자체는 사이트 서버에 저장하지 않습니다.
- Gemini **무료 등급에서는 입력/출력 콘텐츠가 Google 제품 개선에 사용될 수 있습니다.** 개인 정보·저작권상 전송이 허용되지 않는 자료는 업로드하지 마세요.
- 요청 제한: 네트워크 기준 대략 하루 8회, 요청 후 1분 대기. Cloudflare KV 특성상 강한 사용자별 인증/요금 보호가 아닙니다.
- 구동 테스트: API 키 설정·새 배포 이후 'AI 문제 풀이'에서 3문제를 생성하여 확인합니다.
- Gemini API 오류를 인증(401/403), 한도(429), 모델(404), 서버/네트워크 및 응답 형식으로 구분하여 안내합니다.
